# Store Sales Analysis Dashboard

## 📌 Project Overview
This project analyzes store sales data using Microsoft Excel to identify sales trends, product performance, and customer purchasing patterns.

## 🎯 Objectives
- Analyze overall sales performance
- Identify top-performing products and categories
- Understand sales trends
- Create meaningful business insights
- Build an interactive sales dashboard

## 🛠️ Tools & Skills
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Data Analysis
- Data Visualization

## 📊 Project Features
- Sales performance analysis
- Product/category analysis
- Interactive dashboard
- Charts and visualizations
- Filter-based analysis using slicers

## 💡 Key Insights
The analysis helps identify important sales trends, high-performing products, and areas that can support better business decision-making.

## 📁 Project File
- `Store Sales Analysis.xlsx` — Complete Excel analysis and dashboard

## 🚀 Conclusion
This project demonstrates the use of Microsoft Excel for data analysis, visualization, and business decision-making.
